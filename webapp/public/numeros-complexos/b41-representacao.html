(B) Teoria

Plano complexo (Argand-Gauss)

Cada número complexo $z = $a + bi$$ corresponde a um ponto P(a, b) no plano cartesiano: eixo horizontal = parte real, eixo vertical = parte imaginária.

$$z = a + bi \leftrightarrow P(a, b)$$

Afixo

O afixo de z é o ponto (ou o vetor) que o representa no plano. Dizemos “o afixo de z” para o ponto P associado a z.

Módulo

O módulo (ou valor absoluto) é a distância de O ao afixo:

$$\rho = |z| = \sqrt{a^{2} + b^{2}}$$

$|z| \ge 0$ sempre. Geometricamente: comprimento do vetor OP.

Argumento

O argumento $\theta$ é o ângulo que o vetor OP forma com o semieixo real positivo, medido no sentido anti-horário.

$$\theta = \arg(z),\; 0^{\circ} \le \theta < 360^{\circ}$$

Em radianos: $\theta_{\mathrm{rad}} = \theta_{\mathrm{deg}} \cdot \dfrac{\pi}{180}$. Use $\mathrm{atan2}(b, a)$ e ajuste para $[0, 360)$.

Conjugação geométrica

$\bar{z}$ = a − bi é a reflexão de z pelo eixo real. -z = −a − bi é a reflexão pelo origem (rotação de $180^{\circ}$). −$\bar{z}$ = −$a + bi$ é a reflexão pelo eixo imaginário.

Os quatro pontos z, $\bar{z}$, -z, −$\bar{z}$ formam um retângulo (ou quadrado) centrado na origem.

Lugares geométricos

  • $$|z|$ = r$ → círculo de centro O e raio r
  • |z - z_{0}| = r → círculo de centro z_{0} e raio r
  • \\\\\$\$\arg(z)$ = \alpha$ → semirreta partindo de O com ângulo $\alpha$

01Propostos p.732
Dados os afixos no plano, escreva cada número complexo na forma algébrica $a + bi$.

Ideia: o afixo de um complexo z é o ponto P(a, b) no plano de Argand-Gauss; a abscissa a é a parte real e a ordenada b é a parte imaginária, logo $z = $a + bi$$.

  1. Passo 1 — Ler z_{1}: o afixo está em (4, 2), logo a = 4 e b = 2.
    $$z_{1} = 4 + 2i$$
  2. Passo 2 — Ler z_{2}: o afixo está em (0, 4): parte real nula (está sobre o eixo imaginário).
    $$z_{2} = 0 + 4i = 4i$$
  3. Passo 3 — Ler z₃: o afixo está em (−4, 5), 2º quadrante.
    $$z_{3} = -4 + 5i$$
  4. Passo 4 — Ler z₄: o afixo está em (−5, 0): imaginário nulo (número real puro, sobre o eixo real negativo).
    $$z_{4} = -5 + 0i = -5$$
  5. Passo 5 — Ler z₅: o afixo está em (−2, −5), 3º quadrante.
    $$z_{5} = -2 - 5i$$
  6. Passo 6 — Ler z₆: o afixo está em (0, −2): real nulo, imaginário negativo.
    $$z_{6} = -2i$$
  7. Passo 7 — Ler z₇: o afixo está em (6, −4), 4º quadrante.
    $$z_{7} = 6 - 4i$$

Resposta final: z_{1} = 4+2i; z_{2} = 4i; z₃ = −4+5i; z₄ = −5; z₅ = −2−5i; z₆ = −2i; z₇ = 6−4i

Resposta: z_{1}=4+2i; z_{2}=4i; z₃=−4+5i; z₄=−5; z₅=−2−5i; z₆=−2i; z₇=6−4i
02Propostos p.732
Seja $z = $a + bi, com a, b ∈ ℝ. Sabendo que a − b = 1 e $|z|$ = 5, determine z.

Ideia: temos duas condições — uma linear (a − b = 1) e o módulo $|z|$ = $\sqrt{a^{2} + b^{2}}$ = 5. Isolamos a, substituímos na equação do módulo e resolvemos a equação do 2º grau em b.

  1. Passo 1 — Isolar a: de a − b = 1 vem
    $$a = 1 + b$$
  2. Passo 2 — Escrever o módulo: $|z|$ = 5 significa $\sqrt{a^{2} + b^{2}}$ = 5. Elevando ao quadrado (ambos os lados positivos):
    $$a^{2} + b^{2} = 25$$
  3. Passo 3 — Substituir a = 1 + b:
    $$(1 + b)^{2} + b^{2} = 25$$
  4. Passo 4 — Expandir completamente: (1 + b)^{2} = 1 + 2b + $b^{2}$, logo
    $$1 + 2b + b^{2} + b^{2} = 25$$
    $$2b^{2} + 2b + 1 = 25$$
    $$2b^{2} + 2b - 24 = 0$$
    Dividindo por 2:
    $$b^{2} + b - 12 = 0$$
  5. Passo 5 — Resolver por Bhaskara (ou fatoração): Δ = 1² − 4(1)(-12) = 1 + 48 = 49 = 7².
    $$b = (-1 \pm 7) / 2$$
    Assim b = (-1 + 7)/2 = 3  ou  b = (-1 − 7)/2 = −4. (Fatorando: (b + 4)(b − 3) = 0 dá o mesmo.)
  6. Passo 6 — Achar a e montar z:
    $$b = 3 \Rightarrow a = 1 + 3 = 4 \Rightarrow z = 4 + 3i$$
    $$b = -4 \Rightarrow a = 1 + (-4) = -3 \Rightarrow z = -3 - 4i$$
  7. Passo 7 — Verificar $|z|$ = 5 e a − b = 1:
    $$|4+3i| = \sqrt{16+9} = \sqrt{25} = 5\; 4 - 3 = 1 \checkmark$$
    $$|-3-4i| = \sqrt{9+16} = \sqrt{25} = 5\; -3 - (-4) = 1 \checkmark$$

Resposta final: z = −3 − 4i  ou  z = 4 + 3i

Dica: não esqueça as duas raízes da equação do 2º grau — ambas são válidas neste problema.

Resposta: z = −3 − 4i  ou  z = 4 + 3i
03Propostos p.732
Determine o complexo z tal que $|z|$ = $4\sqrt{2}$ e \\\$\arg(z)$ = $135^{\circ}$.

Ideia: conhecemos o módulo $\rho$ e o argumento $\theta$. Usamos a forma trigonométrica z = $\rho$(cosθ + isenθ), ou equivalentemente a = $\rho$ cos $\theta$ e b = $\rho$ sen $\theta$.

  1. Passo 1 — Identificar $\rho$ e $\theta$:
    $$\rho = 4\sqrt{2}, \theta = 135^{\circ}$$
    $135^{\circ}$ está no 2º quadrante (entre $90^{\circ}$ e $180^{\circ}$).
  2. Passo 2 — Valores de cosseno e seno: $135^{\circ}$ = $180^{\circ}$ − $45^{\circ}$, logo
    $$\cos 135^{\circ} = -\cos 45^{\circ} = -\sqrt{2}/2$$
    $$\operatorname{sen} 135^{\circ} = \operatorname{sen} 45^{\circ} = \sqrt{2}/2$$
  3. Passo 3 — Parte real a = $\rho$ cos $\theta$:
    $$a = 4\sqrt{2} \cdot (-\sqrt{2}/2) = -4\sqrt{2} \cdot \sqrt{2} / 2 = -4 \cdot 2 / 2 = -4$$
  4. Passo 4 — Parte imaginária b = $\rho$ sen $\theta$:
    $$b = 4\sqrt{2} \cdot (\sqrt{2}/2) = 4\sqrt{2} \cdot \sqrt{2} / 2 = 4 \cdot 2 / 2 = 4$$
  5. Passo 5 — Montar z e conferir:
    $$z = -4 + 4i$$
    $$|z| = \sqrt{16+16} = \sqrt{32} = \sqrt{16\cdot2} = 4\sqrt{2}\; \arg = 135^{\circ} \checkmark$$

Resposta final: z = −4 + 4i

Dica: no 2º quadrante o cosseno é negativo e o seno é positivo — isso evita errar o sinal de a.

Resposta: z = −4 + 4i
04Propostos p.732
Descreva geometricamente o conjunto A = { z ∈ ℂ : $|z|$ = 3 } e dê a equação cartesiana.

Círculo $|z|$ = 3 (centro O)

Ideia: o módulo $|z|$ é a distância do afixo à origem O. Logo $|z|$ = 3 descreve todos os pontos a distância 3 de O — uma circunferência.

  1. Passo 1 — Interpretação geométrica: $|z|$ = 3 significa “distância de P a O é 3”. Portanto A é a circunferência de centro O(0, 0) e raio 3.
  2. Passo 2 — Equação cartesiana: se $z = $a + bi$$, então
    $$\sqrt{a^{2} + b^{2}} = 3 \Rightarrow a^{2} + b^{2} = 9$$
  3. Passo 3 — Pontos notáveis: a circunferência corta os eixos em
    $$(3, 0) \to 3\; (-3, 0) \to -3\; (0, 3) \to 3i\; (0, -3) \to -3i$$

Resposta final: círculo de centro O e raio 3; equação $a^{2} + b^{2} = 9$

Dica: $$|z|$ = r$ (constante) sempre dá círculo centrado na origem; |z - z_{0}| = r dá círculo centrado em z_{0}.

Resposta: círculo centro O, raio 3; equação $a^{2} + b^{2} = 9$
05Propostos p.732
Seja z = 2 + 3i. Os afixos de z, $\bar{z}$, -z e −$\bar{z}$ formam um quadrilátero Q. Calcule o perímetro de Q.

Retângulo Q: z, $\bar{z}$, -z, −$\bar{z}$ · perímetro 20

Ideia: o conjugado $\bar{z}$ reflete z pelo eixo real; -z reflete pela origem; −$\bar{z}$ reflete pelo eixo imaginário. Os quatro pontos formam um retângulo centrado em O; basta achar os lados e dobrar a soma.

  1. Passo 1 — Listar os quatro pontos (afixos):
    $$z = 2 + 3i \to (2, 3)$$
    $$\bar{z} = 2 - 3i \to (2, -3)$$
    $$-z = -2 - 3i \to (-2, -3)$$
    $$-\bar{z} = -2 + 3i \to (-2, 3)$$
  2. Passo 2 — Ordenar em torno do retângulo: por exemplo no sentido anti-horário a partir de z:
    $$(2,3) \to (-2,3) \to (-2,-3) \to (2,-3) \to de volta a (2,3)$$
    A figura é um retângulo com lados paralelos aos eixos, centrado na origem O.
  3. Passo 3 — Comprimento dos lados horizontais: distância entre (2, 3) e (−2, 3):
    $$|2 - (-2)| = 4$$
    (Mesmo valor entre (2, −3) e (−2, −3).)
  4. Passo 4 — Comprimento dos lados verticais: distância entre (2, 3) e (2, −3):
    $$|3 - (-3)| = 6$$
  5. Passo 5 — Perímetro:
    $$P = 2(4 + 6) = 2 \cdot 10 = 20$$

Resposta final: perímetro = 20

Dica: em geral, para $z = $a + bi$$, os lados medem 2|a| e 2|b|, e o perímetro é 4(|a| + |b|). Aqui 4(2+3) = 20.

Resposta: perímetro = 20  (vértices: (2,3), (2,−3), (−2,−3), (−2,3); lados 4 e 6)

01Complementares p.733 · UEPB
Considere z = (2 − $i^{3}$⁵)/(3 + i). Em qual quadrante está o afixo de z?

Ideia: reduzir a potência de i pelo ciclo de período 4, reescrever o numerador, dividir multiplicando pelo conjugado do denominador e olhar os sinais de Re(z) e Im(z).

  1. Passo 1 — Ciclo das potências de i:
    $$i^{0} = 1, i^{1} = i, i^{2} = -1, i^{3} = -i, i^{4} = 1, \ldots$$
    O resto da divisão do expoente por 4 decide o valor.
  2. Passo 2 — Reduzir $i^{3}$⁵: 35 ÷ 4 = 8 resto 3, pois 4·8 = 32 e 35 − 32 = 3. Logo
    $$i^{35} = i^{3} = -i$$
  3. Passo 3 — Reescrever o numerador:
    $$2 - i^{35} = 2 - (-i) = 2 + i$$
    Assim
    $$z = (2 + i)/(3 + i)$$
  4. Passo 4 — Multiplicar por conjugado do denominador: conjugado de 3 + i é 3 − i.
    $$z = (2 + i)(3 - i) / [(3 + i)(3 - i)]$$
  5. Passo 5 — Expandir o numerador (FOIL completo):
    $$(2+i)(3-i) = 2\cdot3 + 2\cdot(-i) + i\cdot3 + i\cdot(-i) = 6 - 2i + 3i - i^{2}$$
    Como $i^{2}$ = -1: -$i^{2}$ = −(-1) = 1. Logo
    $$6 + (-2i + 3i) + 1 = 7 + i$$
  6. Passo 6 — Denominador:
    $$(3+i)(3-i) = 9 - i^{2} = 9 - (-1) = 9 + 1 = 10$$
  7. Passo 7 — Forma algébrica e quadrante:
    $$z = (7 + i)/10 = 7/10 + (1/10)i$$
    Re(z) = 7/10 > 0 e Im(z) = 1/10 > 0 $\Rightarrow$ afixo no 1º quadrante.

Resposta final: alternativa (d) — 1º quadrante  (z = 7/10 + i/10)

Dica: erro comum: escrever 2 − $i^{3}$⁵ = 2 − i em vez de reduzir $i^{3}$⁵ primeiro. Outro erro: esquecer que -$i^{2}$ = +1 ao expandir.

Resposta: alternativa (d) — 1º quadrante  (z = 7/10 + i/10)

Potências de (1+i) até 16+16i

  2. Passo 2 — Reduzir o ângulo: $405^{\circ}$ = $360^{\circ}$ + $45^{\circ}$, logo cos $405^{\circ}$ = cos $45^{\circ}$ = $\sqrt{2}/2$ e sen $405^{\circ}$ = $\sqrt{2}/2$.
  3. Passo 3 — Calcular ($\sqrt{2}$)^{9}:
    $$(\sqrt{2})^{9} = (2^{1/2})^{9} = 2^{9/2} = 2^{4 + 1/2} = 2^{4} \cdot \sqrt{2} = 16\sqrt{2}$$
  4. Passo 4 — Forma algébrica:
    $$(1+i)^{9} = 16\sqrt{2} \cdot (\sqrt{2}/2)(1 + i) = 16\sqrt{2} \cdot \sqrt{2}/2 \cdot (1+i) = 16 \cdot 2/2 \cdot (1+i) = 16(1+i) = 16 + 16i$$

    $$(1+i)^{8} = (-4)^{2} = 16$$
    $$(1+i)^{9} = 16(1+i) = 16 + 16i \checkmark$$
  6. Passo 6 — Distância d ao afixo (16, 16):
    $$d = \sqrt{16^{2} + 16^{2}} = \sqrt{2 \cdot 256} = 16\sqrt{2}$$

Se Re(1/z) = 1/4, descreva geometricamente o lugar dos afixos de z (z $\ne$ 0).

Círculo centro (2,0), r=2 · origem excluída

Ideia: escrever 1/z em forma algébrica, impor que a parte real vale 1/4, e completar o quadrado para reconhecer uma circunferência — lembrando de excluir z = 0.

  1. Passo 1 — Escrever 1/z: seja z = x + yi, com z $\ne$ 0. Então
    $$1/z = \bar{z} / |z|^{2} = (x - yi)/(x^{2} + y^{2})$$
    Logo
    $$\mathrm{Re}(1/z) = x / (x^{2} + y^{2})$$
  2. Passo 2 — Impor a condição:
    $$x / (x^{2} + y^{2}) = 1/4$$
    Como $x^{2} + y^{2}$ $\ne$ 0 (z $\ne$ 0), multiplicamos ambos os lados por 4($x^{2} + y^{2}$):
    $$4x = x^{2} + y^{2}$$
  3. Passo 3 — Completar o quadrado:
    $$x^{2} - 4x + y^{2} = 0$$
    $$x^{2} - 4x + 4 + y^{2} = 4$$
    $$(x - 2)^{2} + y^{2} = 4$$
  4. Passo 4 — Interpretação: circunferência de centro (2, 0) e raio 2.

Nenhum outro ponto da circunferência tem x = 0 (pois 4 + $y^{2}$ = 4 $\Rightarrow$ y = 0). Portanto o lugar geométrico é essa circunferência excluindo a origem.

Resposta final: círculo centro (2, 0), raio 2, excluindo a origem

Dica: sempre verifique se a origem (ou outro ponto que anule um denominador) precisa ser excluída do lugar geométrico.

Resposta: círculo centro (2, 0), raio 2, excluindo a origem
